# 01 需求访谈材料:问题清单 + 约访话术

> 用途:第 1-2 周找 5-10 家单体酒店验证痛点。目标不是"推销",是**用 20 分钟换回真实业务数据和付费意愿判断**。

## 一、找谁访谈(按优先级)

1. **前客户 / 老同事推荐的单体酒店**(第一优先)—— 有信任背书,最容易约到,也最容易要到真实账单
2. **酒店运营群 / 店长群里的活跃分子** —— 社群里先答疑混脸熟再私聊
3. **自己住过的酒店、家门口的酒店** —— 直接进店找店长/老板,说明来意(行业从业者做调研),成功率不低

**访谈对象画像**:单体酒店(20-80 间房)的 店长 / 老板 / 前台主管 / 老板娘。连锁品牌店(如全季、汉庭)决策权不在店长,暂不访谈。

## 二、约访话术(微信,可直接复制)

### 版本 A:给老同事/熟人(推荐先用这个)

```
X哥/X姐,好久不见!我最近在做一个酒店对账的小工具,想先找几家
单体酒店聊聊实际情况。你之前做的XX酒店(或:你认识的XX店长)
方便帮我引荐一下吗?我就问 20 分钟,不推销,纯粹调研,
问完送一份《酒店对账 Excel 模板》,也算帮他们省点事。麻烦啦!
```

### 版本 B:直接联系酒店(社群/进店)

```
老板您好,我是做酒店管理系统这行的(8 年实施经验),最近在研究
单体酒店月结对账这块的痛点,想请教您三个问题,就 15-20 分钟,
不推销任何东西。作为感谢,送您一份我整理的《酒店对账 Excel 模板》
和《携程/美团账单避坑清单》。您看方便吗?
```

## 三、访谈脚本(核心:只问 3 个问题,其余靠追问)

### 开场(1 分钟)
自我介绍 + 说明目的:"我做酒店系统这行 8 年了,最近想做个对账小工具,想先了解下大家实际怎么对账的。您就随便聊,我问几个问题。"

### 核心问题(20 分钟)
| # | 问题 | 为什么要问 |
|---|---|---|
| 1 | **每月对账要花多久?谁来做?** | 判断痛点频率与人力成本,记下具体数字(如"每星期半天""月底整整 2 天") |
| 2 | **最头疼哪个渠道的账单?** | 携程/美团/飞猪/抖音,每家痛点不同,找出高频渠道 |
| 3 | **现在怎么对?有没有漏过账、吃过亏?** | 了解现状(Excel?人工?代账?),挖掘"损失案例"(钱上的教训最能驱动付费) |

### 追问库(根据回答往下挖)
- "上个月有没发现过对不上的单?差多少?最后怎么处理的?"
- "佣金这块,携程预付/现付、No-show 扣款这些规则您清楚吗?有没有被扣过冤枉钱?"
- "现在这些账单是财务做还是前台做?代账会计管不管这个?"
- "如果有个工具,把携程账单和系统单子自动对一遍,导出差异表,您觉得值多少钱/一年?"

### 收尾(2 分钟)
- 请求:"能不能把最近一期的携程/美团结算单(敏感信息可以涂掉)发我一份?我想研究下格式,做好适配。"
- 送模板/清单(建立信任)
- 问一句:"如果这个工具做好了,您愿意试一下吗?"(测种子意愿)

## 四、记录模板(每家一行,访谈后立即填)

| 字段 | 示例 |
|---|---|
| 酒店 | 某某商务酒店(45 间房) |
| 访谈对象/角色 | 店长 王姐 |
| 渠道 | 携程+美团 |
| 每月对账耗时 | 月底 2 天,前台手工 Excel |
| 最头疼渠道 | 携程(佣金对不上) |
| 损失案例 | 上月 3 单 No-show 被扣佣金 200 元,过了申诉期 |
| 现状工具 | Excel + 代账会计顺带 |
| 付费意愿(0-10) | 7,觉得 2000 以内可以接受 |
| 是否愿试用 | 是 |
| 备注 | 愿意提供账单样本(已涂名) |

## 五、验证通过标准(第 2 周末复盘)

- ✅ 访谈 ≥ 6 家
- ✅ ≥ 70% 每月对账 ≥ 1 天(痛点频率成立)
- ✅ 收集到 ≥ 2 份真实账单样本(打码)(解析器开发素材)
- ✅ ≥ 3 家愿意免费试用(种子客户)
- ✅ ≥ 2 家给出可接受的付费区间(≥ 2000 元)(付费意愿成立)

**若付费意愿普遍 < 2000 元**:不放弃,调整定价模型(如按次收费、与代账公司合作分成),并把访谈结论记入 docs/03(后续迭代文档)。

## 六、注意事项

1. **不要一上来就讲产品**——先听,记数字,不要引导"您是不是很需要这个?"(引导性提问会得到假阳性)
2. **不要贬低竞品**(PMS 自带对账/Excel)——只谈"现状花多少时间"
3. 访谈后 24 小时内填记录,数字优先(时间、金额、次数)
4. 涉及客人隐私的数据一律脱敏,账单样本只用于本地格式研究,不外传
