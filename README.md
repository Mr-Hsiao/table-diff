表对比工具(Table Diff) 
![alt text](qrcode.jpg)
### 为爱发电，请关注公众号：微醺渡人间
- 本地部署的表对比工具:任意多个表格文件(Excel/CSV),配置一个「对账方案」(对号列 + 对比列),即可自动按对号列配对、逐列对比,输出四类结果:一致 / 有差异 / 表一独有 / 对比表独有。
不绑定行业、不绑定系统——酒店 OTA 账单对 PMS、银行流水对台账、供应商对账单、库存进出库……任何"两张表对一下"的场景都能用。
数据不出本机、装一次几乎不用运维、买断收费,适合业余时间维护。
直接使用(无需编程)
方式 A:下载打包好的 exe(推荐,给普通用户)
1. 打开本项目的 Releases 页面,下载 table-diff.exe,放到任意文件夹(如桌面)
2. 双击运行 → 服务在后台自动启动(无黑窗口)→ 浏览器自动打开工具页面
3. 服务已在运行时再双击 → 直接打开页面,不会重复启动
4. 停止服务:运行 table-diff.exe --stop,或在任务管理器中结束进程
exe 同目录会自动生成 data 文件夹(存方案、对账记录和 server.json 端口记录),整个文件夹拷走即备份/迁移。
方式 B:从源码运行(给开发者)
git clone https://github.com/<你的用户名>/table-diff.git
cd table-diff
run_dev.bat
需要 Python 3.10+;run_dev.bat 会自动用系统 Python 启动,端口被占用会自动换端口并在启动时打印实际地址。

核心概念
• 对账方案(映射):存数据库里的一套配置,支持多张表对比(表一~表六),每张表含:
  • 表名:自定义,如"携程账单""PMS流水",上传文件时按表名识别
  • 主键列:该表按哪一列匹配(列用 Excel 位置 A/B/C/D 表示)
  • 对比列:表二及以后,与表一(主表)逐项对比的列对,可多个(对比列一、列二、列三…),数字列可设容差
  • 首行是表头:每张表可单独设置(有些导出文件第一行就是数据)
• 对比逻辑:表一为主表,分别与表二、表三…按各自主键匹配、按对比列逐项对比
• 使用流程:打开程序 → 选择映射 → 按表名上传各表文件 → 开始对账 → 查看/导出结果
• 映射在界面里配置(上传样例文件后自动列出"A: 订单号"便于对照),存 SQLite;不同场景各存一套,随时切换
技术栈
• 后端:FastAPI(Python 3.10+) + SQLite
• 前端:Vue 3 单页(本地静态资源,离线可用,无构建步骤)
• 部署:单机安装包(后端 exe + 前端静态),见 build_exe.bat

使用流程
菜单一:配置映射(先做一次,界面有四步引导)
1. 给对账起名字(如「OTA对账」);默认表一、表二,可「添加表」到最多 6 张
2. 每张表:「这张表是什么?」起个表名(如 携程账单 / PMS流水)→ 上传样例文件 → 选「对号列」(两张表靠哪一列对上号)
3. 表二及以后:「要核对一致的列」——选表一和本表要一样的两列(可多条),数字列可填容差(0.01 = 差 1 分钱以内算一致;数量列填 0)
4. 保存映射——存数据库,多场景各存一套(OTA对账、银行对账、库存核对…)
菜单二:对账工具(每天用)5. 选择映射 → 按表名提示上传各表文件(表一/表二/表三…) → 点「开始对账」
6. 查看四类结果:一致 / 有差异(逐列显示 表一值→该表值)/ 表一有他表无 / 他表有表一无,每条结果标注所属表名
7. 点「导出差异报表」,得到可直接交付的 CSV(带表名、分节与统计)
对账引擎原理
• 多表对比:表一为主表,分别与表二/表三/...按各自主键匹配、按各自对比列逐项对比;结果按表名区分(如"表一有,『PMS流水』无")
• 列位置映射:主键与对比列全部按 Excel 列位置(A/B/C/D…) 定位,与表头名无关——列名怎么变都不影响;每张表可独立配置「首行是表头」
• 主键归一化:1001 / 1001.0 / "1001" 视为同一键;日期统一 YYYY-MM-DD;文本去空白小写
• 值对比:两侧都能解析为数字 → 按容差比较(默认 0.01,可配置);否则按归一化文本比较
• 文件容错:CSV(自动识别 UTF-8/GBK)/ Excel;金额兼容 ¥、千分位、括号负数;日期兼容多种格式
• 配置辅助:上传样例文件时,程序按内置别名(订单号/单号…)与列内容特征(数值列/日期列)自动建议主键与对比列,并显示 A: 订单号 便于对照

API
POST /api/preview              上传文件,返回表头 + 样例行 + 建议主键/对比列
GET/POST /api/plans            对账方案 查询/新建
PUT/DELETE /api/plans/{id}     对账方案 更新/删除
POST /api/recon                选方案 + 上传两个文件 -> 执行对账
GET  /api/export/{run_id}      导出差异报表 CSV
